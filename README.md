DSE Parser

Приложение для парсинга и сопоставления данных из Excel-файлов изделий и деталей (ДСЕ — Детали Сборочных Единиц).

Описание

DSE Parser — это GUI-приложение на Python с использованием `customtkinter`, которое автоматизирует процесс обработки производственных данных. Программа:

- Читает Excel-файлы со списками изделий и деталей
- Сопоставляет детали с изделиями по совпадению кодов ДСЕ
- Записывает результат обратно в Excel-файл изделий

Структура проекта

```
dse-parser/
├── body.py                  # Главный GUI (customtkinter)
├── dse_parcer.py            # Основной класс парсера (логика сопоставления)
├── scripts/
│   ├── excel_enter.py       # Класс для записи данных в Excel
│   ├── excel_reader.py      # Универсальный читатель Excel (.xls, .xlsx, .xlsm)
│   └── handlings/
│       ├── handler_main_tabel.py   # Обработчик таблиц изделий
│       └── handler_detail_tabel.py # Обработчик таблиц деталей
└── static/
    └── template-config.py   # Шаблон конфигурации (пустой)
```

Интерфейс

1. Путь к файлам изделий — выберите Excel-файлы со списком изделий (можно несколько)
2. Путь к файлам деталей — выберите Excel-файлы со списком деталей (можно несколько)
3. Нажмите «Начать» — процесс запустится в отдельном потоке, GUI не зависнет
4. Результат автоматически запишется в первый файл изделий на лист «Изделия»

Формат входных данных

- Файлы изделий: содержат коды ДСЕ изделий
- Файлы деталей: содержат коды ДСЕ деталей с наименованиями
- Сопоставление происходит по частичному совпадению кода ДСЕ изделия в коде детали

Для генерации файла в программе Dse Parser, нужны файлы:
1. Список переводов 28.05.xlsx
2. Файлы отчетов по дсе:
    -ер6.212.112.xls
    -ер7.756.090.xls
    -…
3. 26.01.01-12.31.xlsx

Формат выходных данных

Результат записывается в Excel с колонками:
- `ДСЕ (изделия)` — код изделия
- `ДСЕ (детали)` — код детали
- `Наименование (детали)` — название детали

Зависимости

- `customtkinter` — современный GUI на базе tkinter
- `openpyxl` — работа с .xlsx
- `xlrd` — чтение .xls
- `xlwt` — запись .xls

Особенности

- Поддержка множественного выбора файлов
- Асинхронная обработка (потоки) — интерфейс не блокируется
- Логирование процесса в текстовое поле GUI
- Универсальный Excel-ридер с автоопределением формата и кодировки
